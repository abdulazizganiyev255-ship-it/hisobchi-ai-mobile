# Creative Direction
## Inputs
Signed-off UX flow and truthful content, competitive pattern references, accessibility requirements, device constraints.
## Procedure
1. Deconstruct references by hierarchy, type, rhythm, motion and interaction, not brand copying.
2. Develop exactly 3 structurally distinct visual concepts with identical factual content.
3. Keep mobile first; 320/360/393dp and 1.3x/2x type in view.
4. Demonstrate primary Safe-to-Spend, explanation, Add expense, recent activity and navigation on each concept.
5. Critique every variant for financial trust, usability, feasibility, originality and contrast.
6. Recommend one direction with trade-offs. Wait for an actual selected visual target before implementation.
## Output
3 mockups/spec descriptions, reference anatomy, critical contrast risks, design choice record and visual target ID.
## STOP
No code scaffolding before selected target; no extra FAB rails, fake data provenance or copied artwork.
